# Vote (Plugin)

[![Style](https://github.styleci.io/repos/237491397/shield)](https://github.styleci.io/repos/237491397)
[![Chat](https://img.shields.io/discord/625774284823986183?color=5865f2&label=Discord&logo=discord&logoColor=fff&style=flat-square)](https://azuriom.com/discord)

Grow your community by rewarding users who vote for your server on external listing platforms.

> [!NOTE]
> Support for vote verification on new voting websites can be added by implementing vote verification in
`src/Verification/VoteChecker.php` and submitting a [pull request](https://github.com/Azuriom/Plugin-Vote/pulls).
>
> Due to a recent influx of low-quality, AI-generated voting websites, we now require websites to 
list at least **25 active servers** to be considered for integration.
